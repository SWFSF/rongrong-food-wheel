# 蓉蓉的今日饭饭

给杨皓蓉的手机美食大转盘。首页每次展示 16 道候选，区分「食堂」与「外卖」；食堂标明位置和档口，外卖提供店名、直线距离和可复制的平台搜索词。默认口味为微辣，可在设置里切到正常吃辣或增加忌口。

## 使用

- 直接访问 GitHub Pages 在线地址即可体验全部交互。
- 本地预览需通过静态服务器访问，例如在目录中运行 `python -m http.server 8000`；ES 模块不能可靠地从 `file://` 直接加载。
- 通过 HTTPS 或 localhost 访问时会启用离线缓存；iPhone Safari 可通过「分享 → 添加到主屏幕」使用。
- 换一批、经期模式、忌口、菜品与提醒编辑都保存在浏览器 `localStorage`，不会上传到服务器。

## 数据说明

- 食堂菜单主要参考中国矿业大学（北京）2025 年 12 月 6 日官方「食堂上新」清单，信息核对日期为 2026 年 10 月 19 日。
- 食堂位置参考校内场馆指南；菜单会随季节调整，以现场为准。
- 周边外卖店铺与直线距离参考 OpenStreetMap 周边数据；价格、营业状态和配送范围以美团、饿了么为准。
- 经期与痛经内容只作日常照顾参考，不替代医生诊断或治疗。

## 隐私

姓名只出现在页面文案中。经期状态、忌口、吃过记录和自定义内容只保存在本机浏览器，发布到 GitHub Pages 后也不会回传。
